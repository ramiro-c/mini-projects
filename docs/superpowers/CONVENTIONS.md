# Superpowers conventions

Estas son las convenciones para specs, planes y archivos archivados dentro de `docs/superpowers/`.

## Idioma

- `README.md` del repo, `docs/README.md` y los READMEs de proyecto van en español.
- Specs y planes van en inglés.
- `AGENTS.md` también se mantiene en inglés para que las reglas sean fáciles de reutilizar por agentes.

## Nombres

- Los archivos de spec y plan usan el formato `YYYY-MM-DD-<slug>.md`.
- El `slug` debe ser estable y describir el proyecto o la fase.
- Los folders de proyecto en `projects/` usan números secuenciales de implementación, no el índice de `IDEAS.md`.

## Estado

- Si un spec o plan está completo, se archiva en `archive/`.
- El archivo archivado debe dejar claro el estado y qué documento lo reemplaza.
- Los docs activos no deben duplicar información operativa que ya vive en el README del proyecto.

## SDD

- `.superpowers/sdd/` contiene briefs, reports y progreso de ejecución.
- Ese material sirve como trail de implementación, no como referencia principal para entender el proyecto.
